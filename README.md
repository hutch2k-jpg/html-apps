# HTML Apps

A collection of web apps, hosted with GitHub Pages at
https://hutch2k-jpg.github.io/html-apps/

## Apps

- **Drunken Chef v2** (`drunken-chef.html`) — ESO provisioning compendium: 572 real
  recipes verified against UESP, with effect / ingredient / level / quality filters.
- **Alchemical Workings** (`alchemical-workings.html`) — ESO alchemy: all 38 reagents
  with correct post-Update 51 traits, all 34 effects searchable, potion & poison
  brewing with solvents.
- **Scrying Helper** (`scrying-helper.html`) — ESO scrying: 259 verified leads and
  36 mythics, with found-tracking, expiry countdowns and zone progress.
- **Subliminal Blaster Pro** (`subliminal-blaster-pro.html`) — flash affirmations on
  a schedule with spoken audio. The native Android app (`subliminal-blaster-pro.apk`)
  draws its flashes over any other app you are using.
- **Fireworks** (`fireworks.html`) — interactive fireworks generator.

Every app is a single standalone HTML file — open it in any browser or save it
to your phone. Open `index.html` for the hub page linking them all.

## Notes

- The ESO apps were rebuilt from scratch and audited against UESP (Nov 18, 2026).
  Fireworks is the original file, published as-is.
- The APK (`subliminal-blaster-pro.apk`) is uploaded to the repo separately
  (binary files can't go through the API snapshot push); the download button on
  the hub page links to it here.
